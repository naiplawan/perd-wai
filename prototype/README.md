# Perd Wai prototype

This is the dependency-free Phase 0 prototype for testing the input form, cash-flow explanation, and one-assumption scenario interaction.

## Run locally

From the repository root:

```bash
python3 -m http.server 4173 --directory prototype
```

Then open <http://localhost:4173>.

The `Load example` button uses illustrative values only. Replace them with interview participants' assumptions before treating a result as evidence.
